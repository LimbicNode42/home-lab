### NAS rebalance

Do not delete or move data without an explicit rebalance plan. Recommended sequence:

1. Inspect open files and active writes under `/srv/dev-disk-by-uuid-825a89ab-.../nas/media`.
2. Choose a tool/process such as `rsync --remove-source-files` or mergerfs-compatible rebalancing with dry-run output first.
3. Move cold media from the full branch to `/srv/dev-disk-by-uuid-4ea79d6b-...` in batches.
4. Verify file counts/checksums at each batch boundary.
5. Only then remove empty source directories.
