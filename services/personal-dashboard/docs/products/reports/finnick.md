# Finnick Report Guide

The **Finnick** report panel shows the latest daily betting report produced by the Finnick workflow. It is an informational report for review, not a betting instruction.

## Where to find it

Open **Reports**, then look for **Finnick — Daily Betting Report**.

## What it does

The panel renders the latest available Finnick report as preformatted text. It loads when the Reports tab opens and can be reloaded with **Refresh**.

## How to use it

1. Open **Reports**.
2. Read the Finnick report body.
3. Use **Refresh** if the report should have updated recently.
4. Treat any picks, probabilities, or commentary as inputs for human judgement.

## Data source and freshness

The report is generated by a scheduled workflow outside the dashboard and copied into the dashboard runtime cache. The dashboard only reads and displays the latest sanitized text artifact. It does not generate odds, fetch market data, or place bets.

## Empty and error states

- **No report yet** means the scheduled report has not produced a current artifact.
- **Not configured** means this dashboard instance does not have a Finnick report source wired in.
- **Unavailable** means the dashboard could not read a usable report.

## Known limitations

- This is not financial advice, betting advice, or an automated betting system.
- The dashboard does not verify that odds or markets remain current after the report is generated.
- The report format is plain text, so complex tables or rich formatting may be limited.

## Troubleshooting hints

- If the report is missing before the daily generation time, wait for the next scheduled run.
- If it is still missing after the expected time, check the Finnick report workflow and runtime snapshot sync.
- If the panel shows stale-looking text, refresh the tab before assuming the upstream job failed.
